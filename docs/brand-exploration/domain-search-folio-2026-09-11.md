## Method

Read-only HTTPS GET requests to `https://rdap.verisign.com/com/v1/domain/<domain>`, with five concurrent requests at most and one attempt per candidate. The requests inspected HTTP status and the returned domain name for existing records, without collecting registrant personal information. There were 20 HTTP 200 results and five HTTP 404 results; no inconclusive timeout or rate-limit responses occurred.

Results and prices can change after the timestamp. Recheck the final preferred name directly with the registrar before any purchase decision. The search stopped at the authorized small initial batch rather than expanding indefinitely.
